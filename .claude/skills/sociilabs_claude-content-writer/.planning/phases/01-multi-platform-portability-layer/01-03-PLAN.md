<objective>
Migrate the Claude Code adapter's shared orchestration file from memory-key-first storage to
file-first storage, per the locked decision that this migration happens now, not later, with the
memory tool becoming an optional fast-path cache on top of the new schema.

Purpose: ADAPTER-01 requires the existing `/writer:*` commands to keep working unchanged from the
user's perspective while their internal state storage becomes the portable schema defined in
skills/state-schema.md (Plan 01-01). This is the single highest-regression-risk file in the whole
migration — every command transcludes it.
Output: `skills/shared-context.md` rewritten to be file-first; `scripts/postinstall.js` updated so
an installed copy of shared-context.md can resolve its reference to state-schema.md.
</objective>
