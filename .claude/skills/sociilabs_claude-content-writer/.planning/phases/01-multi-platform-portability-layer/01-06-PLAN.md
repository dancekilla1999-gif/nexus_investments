<objective>
Build the one shared script that populates every chat-platform adapter's knowledge/reference
folder directly from the canonical `references/` directory, so the three adapters this phase ships
(ADAPTER-02/03/04) never carry independently-edited duplicate copies of the content-strategy
knowledge.

Purpose: Success Criterion #3 in ROADMAP.md explicitly requires the three chat-platform adapters
be "built from the same shared reference docs rather than three separate copies." Custom GPT
knowledge files and Gemini Gem knowledge sources are read-only, set at configuration time — so
"build from the same source" has to mean a repeatable copy step, not a live shared filesystem.
Output: `scripts/build-adapter-knowledge.js`, invoked later by plans 01-08/01-09/01-10 to populate
each adapter's knowledge folder.
</objective>
