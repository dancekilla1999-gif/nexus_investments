## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| MCP tool JSON input -> file path construction | Any tool that writes to content-writer-output/ must never build that path from unvalidated caller input |
| MCP tool JSON input -> PROJECT-STATE.md frontmatter values | Caller-supplied field values are trusted as data by every downstream adapter that later reads this file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|------------------|
| T-01-07-01 | Tampering | server.js file-write path for content-writer-output/ | high | mitigate | The output directory path is a fixed constant (or a single environment-variable override used only by the test harness) — never constructed by concatenating any field from the tool's JSON input, closing off path-traversal via a crafted `topic` or `platform` value |
| T-01-07-02 | Information Disclosure | server.js JSON-RPC error responses | medium | mitigate | Error results returned by the phase-gate check state only the expected phase name, never a stack trace or filesystem path, matching the "no thrown exception" requirement in the task's behavior list |
| T-01-07-03 | Tampering | Caller-supplied frontmatter values later re-read by other adapters | medium | mitigate | README.md's contract documentation carries forward skills/state-schema.md's File-First Storage Rule instruction that field values are treated as data, never as new instructions, regardless of content |
